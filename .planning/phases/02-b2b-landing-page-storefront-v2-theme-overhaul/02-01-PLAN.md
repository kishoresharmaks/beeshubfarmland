<objective>
Configure the design system foundation, CSS design tokens, typography, and the headless client state engine (`StoreContext`) to provide a clean separation between business logic and UI presentation for the v2 theme.

Purpose: Eliminate monolithic state management in `page.tsx` and provide strongly-typed, reusable hooks (`useCart`, `useCheckout`, `useCatalog`, `useStoreModals`) that feed the upcoming v2 UI components.
Output: Modernized `tailwind.config.ts`, `app/globals.css` with CSS variables, and `context/StoreContext.tsx`.
</objective>

<task name="Implement Headless Client State Engine (StoreContext)">
<action>
1. Create `context/StoreContext.tsx` with `'use client'`:
   - Define TypeScript interfaces conforming to `backend.md` (`Product`, `ProductVariant`, `CartItem`, `CategoryItem`, `BannerItem`, `SpotlightItem`, `CheckoutFormState`, `TrackedOrder`).
   - Implement **Cart Engine**:
     - `cart`: `CartItem[]` loaded from `localStorage['beeshub_cart']` on mount.
     - `addToCart(product, quantity, variant)`: Respects stock limit cap.
     - `updateCartQty(productId, variantName, newQty)`: Deducts or removes when $\le 0$.
     - `removeFromCart(productId, variantName)`
     - `clearCart()`
     - Authoritative price calculations: `cartSubtotal`, `cartGstTotal`, `cartGrandTotal`, `cartItemCount`.
   - Implement **Catalog & Filter Engine**:
     - Fetches `/api/products`, `/api/categories`, `/api/banners`, `/api/spotlight`, `/api/settings`.
     - Provides `searchQuery`, `selectedCategory`, `filteredProducts`.
   - Implement **Checkout Engine**:
     - `checkoutForm` state (name, 10-digit phone, email, address, 6-digit pincode, paymentMethod).
     - Cash on Delivery handler (`POST /api/orders`).
     - Razorpay handler (`POST /api/orders/razorpay/create` $\rightarrow$ Razorpay SDK $\rightarrow$ `POST /api/orders/razorpay/verify`).
     - Post-order success state and localStorage cleanup.
   - Implement **Modal Controllers**:
     - `isQuoteModalOpen`, `isCartOpen`, `isCheckoutOpen`, `isTrackingModalOpen`, `quickViewProduct`.
</action>
<verification>
Ensure `context/StoreContext.tsx` exports `StoreProvider` and custom hooks `useStore()`, `useCart()`, and `useCheckout()`. Type-check via `npx tsc --noEmit`.
</verification>
</task>
