# Bees Hub Farmland — Homepage Redesign & Optimization Upgrade Prompt

**Target Website:** https://beeshubfarmland.com/  
**Primary Objective:** Transform the homepage into a premium agricultural products and dual-track B2C ecommerce + B2B wholesale/private-label platform.

## Design System Tokens
- Primary forest green: `#173F2B`
- Deep green: `#102E20`
- Warm cream: `#F7F4EB`
- Light background: `#FFFFFF`
- Earth brown: `#A97843`
- Muted green: `#E8EFE6`
- Primary text: `#202820`
- Secondary text: `#6B756B`
- `Outfit` (`--font-outfit`) for headings + `Inter` (`--font-inter`) for UI & body copy.
